# s21_cat

Отдельная копия проекта `cat.rar` с исправлением флага `-E` для строк с `\r\n`.

Файлы:
- `s21_cat.c` — исходный код утилиты на C11;
- `Makefile` — сборка и команда `make test`;
- `test_cat.sh` — сравнение с системным `cat` на временных файлах;
- `s21_cat` — исполняемый файл для Linux x86-64;
- `s21_cat_fixed.zip` — архив этих файлов.

На компьютере с другой архитектурой пересобери программу командой `make rebuild`, затем запусти `make test`.
